Instrucciones de inicio

1-  Clonar el repo
2-  Abrir una terminal de git bash en la carpeta root y correr "npm install" para instalar node_modules
3-  Correr "npm install axios" para instalar la biblioteca axios
4-  Correr "npm start" para iniciar el local host
5-  Si el paso anterior no funciona, es posible que haya un problema de compatibilidad de React-19
6-  El problema mas comun es la libreria "ajv", instalarla usando "npm install ajv --legacy-peer-deps"
7-  Volver a correr "npm start"



Funcionamiento esperado de la APP

1-  Seleccionar una categoria en el menu
2-  Seleccionar una dificultad
3-  Iniciar la partida con el boton
4-  Jugar la partida seleccionando las opciones
5-  La partida finaliza luego de la quinta pregunta
6-  Muestra los resultados
7-  Da la opción de volver al menu principal
